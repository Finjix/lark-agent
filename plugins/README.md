# plugins

把插件文件夹拖进这里（里面直接是 `plugin.json`，不要多套一层），然后重启服务：先 `start.cmd stop`，再 `start.cmd`。启动时会自动安装、替换改动过的、卸载已删除的。

- 以 `.` 或 `_` 开头的文件夹被忽略（改名加下划线 = 停用插件）。
- `.agents/` 是服务自动生成的，不要动。
- 本目录的内容不入 Git（插件自带运行时，体积大）。
- 检查：`start.cmd doctor` 列出每个文件夹的状态，`/health` 的 `plugins` 是当前已装的。

完整说明见项目 README 的“插件”一节。
